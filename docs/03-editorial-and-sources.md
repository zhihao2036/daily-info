# 采集、归并与编辑规则

所有网站文章、标题、评论和模型输出均为不可信数据，不能改变预算、允许主机或发送目标。来源目录是候选清单，可读性由部署者在目标 Worker 环境验证，不代表作者长期为这些网站提供抓取保证。

## 来源和日期

支持 RSS/Atom、GitHub Releases 和静态 HTML 列表。RSS 可能只有摘要；HTML 选择器为空时仅保留 metadata_only；普通请求已成功但内容为空时可选 Browser Run 渲染。遇到 401/403/429 或登录、验证码等控制信号不得通过浏览器绕过。HTTP 文章链接仅在来源显式设置 upgradeHttpLinks=true 时升级为 HTTPS，仍逐跳校验允许主机。

正式日报在北京时间 08:00 冻结候选，以最近 24 小时入库或有实质更新的版本为主；发布日期必须明确，不晚于 cutoff，最多补录 72 小时内的文章。旧文章不会因重试元数据或 revision 增加而变成新新闻。没有 published 的 Atom 条目不把 updated 当作发布日期；仅有图片、元数据或日期缺失的条目不能凑数。

候选按来源轮转，再受总数量限制；公开模板最多 60 篇候选、10 篇深入处理。最终最多 10 个事件，不保证必须达到固定数量，每个来源和组织最多两条。来源 priority 和 core 属性不是强制收录配额。

## 模型筛选

Deep reading 前先过滤招聘、活动报名和明显营销标题，再给模型标题、正文、来源属性、发布日期和内容质量。优先模型/API、Agent 工程、开源工具、安全、弃用及破坏性变化；官方 partial 可以作为一手发布摘要，但不能推断摘要未说明的事实。

| 维度 | 权重 |
| --- | --- |
| AI / Agent 相关性 | 35% |
| 影响 | 25% |
| 证据质量 | 20% |
| 新颖程度 | 15% |
| 可操作性 | 5% |

最终综合分至少 60。分数由模型判断，不是客观准确率；评分后挑选最多十篇进入归并和编辑，并做来源多样性约束，不保证覆盖所有重要消息。合格内容不足时少发，不降低证据门槛补齐数量。

## 事件与证据

标题推导的组织、产品、版本和 changeKind 只提供候选事件键。同一事件的多源报道可以归并，优先官方来源；跨标题归并需高置信度、共同主题证据和无明确版本冲突。事实哈希与最近 30 天 sent/uncertain 的快照比较，相同事件、相同事实不再推送；这不是完美的语义重复识别。

每篇文章可提供最多十二段、每段最多 240 字符的实际正文证据。事实引文必须可定位到不可变原文，数字必须有支持，模型不能生成外部链接；不合格卡片拒绝或按预算作一次受控修正。中文摘要是有引用支持的模型转述，影响与建议是模型判断，引用匹配不代表独立事实核查。

只依据 RSS 摘要的条目标明非全文，历史补录标明日期。模型失败时明确降级，不能静默声称编辑成功。来源覆盖页脚区分本期候选数和最终事件引用数；未收录不等于采集失败，多源事件可让引用数之和大于事件数。

## 配置

来源模板均为 discovered、enabled=false。共享 defaults 只允许 kind、enabled、core、priority、authority、intervalHours、verification、browserFallbackEnabled；身份、URL、允许主机和选择器逐源配置。完整运行时 schema 展开后再验证，doctor 检查绑定不超过 5120 UTF-8 字节。

费用、深读数量和筛选上下限均以自己的 APP_CONFIG 为准。公开模板只包含没有真实调用的合成样例，不包含某个账户的来源健康记录或文章库。
